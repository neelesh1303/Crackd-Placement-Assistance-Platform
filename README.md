Crackd — AI POwered Placement Assistance Platform
Crackd is a full-stack MERN application that helps students log interview experiences, track company-specific preparation, and generate AI-powered study roadmaps.

Key Features:
->Log interview experiences with round-wise problems and tips
->Generate personalized roadmaps using Hugging Face Inference API
->Progress dashboard with readiness indicators, streaks, and checklist management
->JWT authentication with role-based access control
->Company explorer with difficulty tags and responsive UI components

Tech Stack
React, Node.js, Express, MongoDB, Mongoose, Tailwind CSS, JWT, Hugging Face API, Axios
